SPORTS-HUB

隐私政策

生效日期：2026 年 10 月 31 日 · 适用范围：sports-hub 的 Strava 至 Google Calendar 同步功能及本说明网站。

访问与处理的数据

  • Strava 活动数据：活动标识、名称、类型、起始时间、时区、时长、距离和累计爬升等同步所需字段。接口响应可能包含其他活动字段，待处理活动可能暂存于本地队列。
  • Google 日历数据：同步关联事件的标识、标题、起止时间、描述及来源标识，用于核验和维护对应关系。
  • 授权与运行数据：OAuth access token、refresh token、目标日历配置、同步时间、事件映射、待处理记录及运行诊断信息。

用途和数据流向

数据仅用于用户要求的运动日历同步、去重、故障排查和维护。程序从 Strava 获取活动，将名称、时间、类型、距离、爬升和活动关联标识发送给 Google Calendar。日历事件的可见性受目标日历的共享设置控制。

应用通过 HTTPS 与 Google 和 Strava 通信。凭据、同步状态及可能含活动信息的日志存放在运行设备上；它们不属于本公开网站的内容。请保护运行设备和备份的访问权限。

共享与限制用途

维护者不出售个人数据，不将 Google 用户数据用于广告、用户画像或训练通用人工智能模型。除提供同步所需的 Google、Strava 服务外，不主动将这些数据传给其他服务。用户主动提供诊断信息时，维护者仅将其用于处理该问题；请勿发送令牌或不必要的个人活动信息。

sports-hub 使用及向其他应用传输从 Google API 获取的信息将遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、撤销与删除

本地凭据和同步状态保留至用户删除；日志和备份按运行设备的配置保留，本应用不承诺统一的自动清理期限。写入 Google Calendar 的事件会保留至用户或授权同步操作删除。

您可先停止同步，再通过 Google 账号的第三方连接设置撤销 sports-hub 的授权；Strava 授权可在其账号设置中撤销。撤销授权不会自动删除已有日历事件或本地文件。如需彻底清理，还应删除相关日历事件、本地令牌、同步状态、日志及备份。停止同步后再清理，避免数据被重新写入。

说明网站

本网站托管于 GitHub Pages，未添加分析脚本、广告或表单。访问网站时，GitHub 可能按其隐私声明处理 IP 地址和请求日志等技术数据。访问本站不会授予日历权限。
